# Глоссарий

| Термин | В коде | Значение |
|---|---|---|
| Плейсет | `Playset` | Набор модов с порядком загрузки в Paradox Launcher |
| Позиция | `position` | Место мода в плейсете; 0 — первым. Ниже в списке = бóльшая позиция |
| Мод | `ModEntry` | Мод плейсета вместе с `descriptor.mod` и индексом |
| Индекс мода | `ModIndex` | Файлы, объекты `common/` и ключи локализации одного мода |
| Ваниль | `Source::Vanilla` | Файлы самой игры (папка `game/`) |
| Конфликт | `Conflict` | Один файл / объект / ключ локализации определён в двух и более источниках |
| Уровень конфликта | `ConflictLevel` | `File`, `Object` (база + ключ в `common/`), `Loc` (язык + ключ) |
| Победитель / проигравший | `winner` / `losers` | Чья версия загружается в игре / чья теряется |
| Причина победы | `WinReason` | `LowerInPlayset`, `LaterFilePath`, `EarlierFilePath`, `ReplaceFolder` |
| Пометка | `Verdict` | `Intended` (задумано), `Suspicious` (подозрительно), `Vanilla` (перезапись ванили) |
| Compatch | `DepGraph::compatches` | Мод, зависящий от двух и более модов плейсета, — склейка для совместимости |
| LIOS | — | «Last In, Only Served»: из одинаковых объектов побеждает прочитанный последним |
| replace-папка | `is_replace` | `localization/replace/…` или `localization/<язык>/replace/…`: ключ перебивает обычный |
| Правило порядка | `Rule` | «A раньше B» из `rules.toml` |
| Калибровка | `calibrate` | Сверка нашего прогноза победителей с `database_conflicts.log` игры |
| Сессия | `session` | Загрузка плейсета (и лога конфликтов игры) для анализа; общая для CLI и приложения |
